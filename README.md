# conure ToolKit

A website about conures made for new bird owners looking for basic information on how to take care of conures.

This website helps bring an understanding of conure species, health, training, genetics, enrichment, housing, and more resources.

# Why i made it

I created this website to improve my skills in coding CSS and HTML since I was still very new to these languages. I wanted to combine an interest in and love for conures to help build my understanding through research and help others who are also like me learn.

# How to run and view the website

You can view the project by running it locally on your computer.
